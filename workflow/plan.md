# 计划与里程碑

## 当前路线

已获用户授权实施 Windows 原生轻量版。入口是主编辑器严格空文本 `←` 和 `/session-browser`；核心是历史浏览、搜索、预览和恢复。使用 Pi 1.4 公开 API 自研，不移植 Linux 后台 host。

## 持续风险

- 跨项目切换会替换当前运行时，不是把任务放到后台；切换后旧上下文失效。
- 轻量版不检测其他 Pi 进程是否写同一文件；恢复前需要用户确认，不提供“接管活跃会话”的承诺。
- 发现 API 为搜索读取完整历史；全局历史多时存在扫描成本，改版默认全部项目，可用 `Tab` 切换当前项目范围。
- 编辑器共存策略为不覆盖已有自定义编辑器；其他扩展晚于本扩展安装编辑器时可能取代左键入口，命令仍是退路。
- 公开 API 也有版本边界：依赖按 Pi 1.4 系列约束，升级前重新运行自动化与人工验收。
- 用户已授权新增命名；仅当前会话走原生元数据，其他会话使用扩展别名，恢复为当前后才转原生名称。当前模型自动拟标题已获授权；其他模型请求、全局安装、后台驻留和破坏性管理仍需另行授权。开发测试不发真实模型请求。
