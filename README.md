# PiSessionViewer

面向 Pi 的轻量终端历史会话浏览器，参考 Codex CLI command center 的项目列表与详情交互。**不是后台多 Agent 管理器。**

## 当前功能

- 主编辑器完全为空时按 `←` 打开；有文字、空格、换行或自动补全时保留原生行为。
- `/session-browser` 命令入口；已有其他自定义编辑器时不覆盖它，改用命令。
- 真正覆盖终端可视区的深色页面；退出恢复聊天与草稿，不把浏览器插入聊天流。
- 默认全部项目，支持当前项目过滤、项目分组 / 最近活动视图；会话身份色稳定，选中行蓝底。
- 搜索标题、项目路径、会话 ID 和消息文本；多个关键词采用 AND 匹配。
- 宽屏 Tasks 列表 + Task details；展示模型、推理级别、项目、当前分支首问与最后助手回复，窄屏可切换详情。
- `?` 打开 Navigate / Tasks / View 帮助页；`F3` 显式开启搜索，搜索中输入快捷键字母不会触发动作。
- 明确确认后恢复；运行中或有排队消息时拒绝切换。跨项目恢复由 Pi 重建目标项目运行时。

## 试用

要求 Node `>=22.19.0`、Pi `>=1.4.0 <1.5.0`。开发与自动化验证环境为 Windows / Node 24 / Pi 1.4.0；其他终端尚未人工实测。

在本项目目录中：

```sh
npm ci
pi -e .
```

仅本次启动加载，不修改你的全局扩展设置。进入 Pi 后使用 `/session-browser` 或在空输入框按 `←`。

需要长期使用时，执行以下命令并重启 Pi：

```sh
pi install .
```

本地包安装请保留源码目录。建议全局安装，以便跨项目恢复后仍能加载；项目级安装可能在切换到其他项目后不再可用。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| `↑` / `↓` | 选择会话（遵循 Pi 的列表方向键配置） |
| `PageUp` / `PageDown` | 翻页选择 |
| `Enter` | 确认恢复选中会话；当前会话则直接返回 |
| `Tab` / `Shift+Tab` | 全部项目 / 当前项目（`Ctrl+O` 仍兼容） |
| `F3` | 打开 / 关闭搜索 |
| `g` | 项目分组 / 最近活动 |
| `?` | 快捷键帮助 |
| `Ctrl+R` | 重新扫描 |
| `Shift+↑` / `Shift+↓` | 滚动详情 |
| `←` / `→` | 窄屏列表 / 详情（搜索模式保留光标移动） |
| `Esc` | 从帮助 / 搜索返回；普通模式关闭 |
| `Ctrl+C` | 直接关闭浏览器，不切换 |

## 安全与范围

- 浏览、搜索、预览不调用模型，不新建或改写历史文件。显式恢复会话后，Pi 按正常会话生命周期运行。
- 详情字段跟随当前分支；首问和最后回复各限制 6000 字符，尊重完整分支的上下文编辑，包括删除与空替换；不展示思考和工具结果。超过 16 MiB 的文件跳过详情读取，仍可恢复。
- 16 MiB 限制仅约束详情预览：Pi 自带的发现 API 为建立搜索索引仍会扫描完整历史，历史很多时默认的全局扫描可能较慢，可用 `Tab` 限定当前项目。
- 只有当前进程会话显示真实 `Ready` / `Working` / `Queued`；其他历史统一标记 `Saved`，**不代表它已停止运行**。轻量版不能判断其他进程是否正在写同一会话，恢复前务必确认。
- 恢复会替换当前会话与项目运行时，草稿不会迁移；浏览器退出而不恢复则保留原编辑器。
- 没有后台驻留、远程连接、实时多会话状态、跨进程停止、置顶/归档/删除、worktree 和自动命名。不替代 Pi 原生 `/resume` 的全部管理功能。
- 缺失的目标目录、不支持的旧格式、损坏文件会显示错误；不通过 `process.chdir()` 或原地迁移修复。
