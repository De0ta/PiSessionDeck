# v0.6 独立恢复转换页

## 用户确认的外观

选择历史会话后切到独立页面，而不是在聊天页面打开确认弹窗。只给上方内容块设置深灰背景，保留截图的左上标题、灰色解释、编号选项和整行蓝色选中条；下面以终端默认底色留空，并遮住旧聊天。

- 同目录：`Resume session`，目标会话标题和共用`Directory`，选项`Resume this session / Back to sessions`。
- 不同目录：`Working directory · resume`，分别列出`Session`与`Current`路径，选项`Use session directory and resume / Back to sessions`，说明要切换项目运行时。
- 当前会话：直接退出浏览器回聊天，不额外确认。

目录比较使用已有`pathKey()`，规范化绝对路径/分隔符/末尾分隔符，并在Windows忽略大小写；不解析符号链接为同一物理目录。

## 组件与状态

`src/resume.ts`的`ResumeFlow`作为一次`ctx.ui.custom()`的根组件，在原`SessionBrowser`和`ResumePage`间切换，不叠加第二个确认弹窗。底层仍使用Pi公开全终端覆盖层，以避免替换聊天主组件或写入聊天流；视觉与交互上是独立页面。

浏览器通过可选`onSelect`交出选择，不销毁自身。返回时使用原实例，保留搜索/分组、展开量、选中项、列表位置与详情滚动；输入焦点随当前页面转移。关闭、焦点让出或session_shutdown会终止在途预检，迟到结果不切换会话。

两页都逐行生成完整终端宽高。上方内容块使用`#262626`，选择行使用既有蓝色，键名白色；块外用SGR reset和空格恢复终端底色，同时遮住底层内容，不把整屏涂灰。长路径和说明换行，小窗口支持翻页；错误出现时自动滚入视口，窗口resize不截断终端行宽。

## 按键

| 按键 | 转换页行为 |
| --- | --- |
| 上/下或Pi列表方向键绑定 | 选择继续或返回 |
| `1` / `2` | 选择对应选项，不立即提交 |
| `Enter` / `→` | 执行选中项 |
| `Esc` / `Ctrl+C` | 返回原浏览器 |
| `PgUp` / `PgDn` | 滚动长路径、说明或错误 |

异步预检期间可返回，预检会被取消。提交`ctx.switchSession()`后Pi没有公开撤销机制，此时显示等待并暂停按键，直到宿主取消、错误返回或新会话取代当前运行时；不能假装Esc仍能撤销。权限/信任等原生对话出现时保留原焦点让出机制。

## Pi 1.4 API边界

公开扩展接口为`ctx.switchSession(sessionPath, { withSession? })`，没有`cwdOverride`。宿主内部虽有目录覆盖能力，但交互适配层不会转发插件强塞的参数。

所以本版只支持恢复到会话记录的目录，不显示“使用当前目录”“始终使用当前目录”等无效选项，不持久化假偏好，不使用私有API、`process.chdir()`、历史头改写或另启后台宿主绕过限制。同目录也仍由Pi执行会话恢复，不能声称一定不重建运行时。

## 安全检查

1. 确认前检查当前任务空闲、无排队消息且编辑器严格空文本；任何草稿，包括空格和换行，都要求先返回聊天保存或清空。旧版“草稿不会带过去”的提示不准确，Pi宿主可能迁移编辑器文本，本版不再作此承诺。
2. `src/resume-target.ts`使用只读句柄，核查目标是存在的非空普通文件；最多读取64 KiB头部，不完整加载大历史。
3. 严格解析首行，核查`type=session`、非空ID与列表相同、版本1/2/3、有效时间戳、绝对cwd与列表相同；列表过期或异常则要求刷新。
4. 核查目标cwd存在、为目录且可读取/进入；核查读前后文件身份与size/mtime/ctime未变化。检查过程中不创建缺失文件，不迁移旧版本，不写会话。
5. 预检后再检查任务/队列/草稿，随后提交官方恢复。检查前后发生变化、宿主返回`cancelled`或可捕获异常，都保留页面并显示错误，允许重试或返回。
6. 宿主成功替换后旧ctx失效；session_shutdown关闭根组件，异步结果不再调用旧状态/UI。实际恢复由Pi负责，它可能迁移旧文件或在项目初始化内部失败；外层不能保证拦截宿主的进程级致命错误。

此预检只能减少风险：不能保证历史正文完全有效，不能消除提交前最后瞬间的文件系统竞态，也不能检测另一个Pi进程是否仍在使用会话。页面继续显示并发写入提醒。缺失cwd在插件页内提前阻止；Pi原生`/resume`自身的缺失目录回退是另一个流程，不在本页伪造。

## 人工验收

1. 在可丢弃会话中`pi -e .`，选择同项目另一历史，确认显示简化页；选择其他项目，确认显示目录比较页。
2. 检查顶部灰块、下方默认底色、蓝色整行选择、白色键名；不能露出旧聊天，也不居中弹窗。
3. 先搜索、分组和展开至第6条，滚动详情后进入转换页；Esc返回时各状态保持。
4. 在命令入口带空格/换行/实际草稿时确认恢复，应在页内提示，不切换也不清空文字；退出后可自行保存。
5. 用临时目录测试文件被删除、空文件、cwd被删除或ID变化；只显示错误，不创建替代会话。恢复前确认没有其他进程写目标。
6. 明确接受替换当前会话后执行一次真实恢复；验证插件在目标项目的加载策略、取消与reload，并核查新会话和目录。
