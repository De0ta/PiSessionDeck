## 实现边界

### 新建与未落盘会话

- `n` 在当前 cwd 调用原生新建，不带 prompt，不自动发送消息或调用模型。
- 当前会话尚未落盘仍显示一行，状态为 `Unsaved`；不能删除当前会话，也不能 pin / fork。落盘后重新扫描更新。
- 新建、分叉和恢复涉及运行时切换，需遵守任务、队列、草稿保护；不能因新操作绕过保护。

### 分叉

- 当前已保存会话：`ctx.fork(leaf, { position: 'at' })`，保留当前叶节点及末次回复，不回退到提问前。
- 当前原生 fork 在新 runtime 的 `session_start`（reason 为 fork）追加 ` · Fork`，不在旧上下文写名称；新会话不继承 pins。
- 历史会话：不先恢复源、不用打开源会话的方式迁移。只读快照严格解析 v1/2/3，仅在私有副本转换旧格式；保留有效分支、原生引用的传递闭包及 latest reply，写入新的 v3 文件后调用 `ctx.switchSession`。
- 历史快照上限16 MiB；损坏 JSONL、无有效对话、重复ID、断链/循环、缺失引用、未知版本/记录/消息格式均安全拒绝，不猜测修复。源文件不改写。
- 保留 system 消息、sections、工具定义增删和压缩中的 systemMessage；全局最新 session_info 在分支裁剪前读取，插件手动别名优先，避免把旧分支名作为新标题。
- 旧会话缺少 cwd 时不能推测源项目，明确拒绝 Fork；这种会话可在空 cwd 身份匹配的前提下安全捕获与删除。
- 新文件具有独立身份、来源关联与 ` · Fork` 标题，不继承置顶。创建与打开是两步，不是文件系统事务。
- 已创建但未打开的 Fork 保留：原确认页重试复用已创建文件；返回后刷新可找到并打开。不因打开失败或返回而删除文件，也不应盲目再次创建。

### 置顶

- `p` 切换 Pin / Unpin；Project、Recent、Model、Status 四种模式均有独立 `Pinned` 区。
- 先应用搜索和当前项目过滤，再分组；置顶项不在普通组重复，按置顶时间倒序，每组默认5条，逐次再展开5条。
- 仅保存插件元数据，不改源会话。位置为 `getAgentDir()/pi-session-viewer/pins`；按规范化会话路径与ID计算 sha256，分别保存记录，通过临时文件写入与原子 rename 提交，不使用项目内配置。

### 永久删除

- `Delete` 仅允许删除非当前单个会话文件，不是回收站；不递归删除目录、不删除项目、不级联删除 Fork、不停止其他进程。
- 参照 `pics/删除对话.jpg`：列表上方居中深灰弹层，默认 `Cancel`，选中项为蓝条。数字只改变选择，`Enter` 才提交；返回不删除。
- 确认前后复核路径、会话ID/cwd及 revision；删除头部读取上限1 MiB。未知格式/身份不符/修订变化/非普通文件等安全拒绝，不能仅凭列表缓存删除。
- 无跨进程锁。身份与 revision 检查不能消除最后检查到 unlink 之间的竞态；`Saved` 也不表示其他进程已停止。用户应先确认没有其他实例写入，不能宣称安全接管。

### 菜单、输入与标题

- `a` 打开 New / Fork / Pin（或 Unpin）/ Rename / Delete 操作菜单；保留 `r` 命名、`d` 窄屏详情旧按键。
- 搜索、重命名等输入模式中，字母仍为文本，不触发新建、分叉、置顶或菜单。
- 自动标题不得含“短会话标题-”“会话标题:”“Short session title”等标签前缀：system prompt 已加强，`cleanModelTitle` 对模型结果清理。只处理新结果，不改旧标题、不重新请求模型；不新增付费用途。
