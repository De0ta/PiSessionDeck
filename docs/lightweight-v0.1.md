# 轻量版 v0.1：设计与验证

> 本文保留初版实施记录，其中默认范围、快捷键与预览布局已被后续改版替换。当前行为及验收见[全屏 v0.2](fullscreen-v0.2.md)。

## 实施决策

用户确认先实现 Windows 友好的轻量版。采用 Pi 1.4.0 公开 API 自研，不安装或移植 `sidstack/pi-codex-agents`，不引入 Linux host、私有 UI 访问或跨进程控制。现有开源调研仍保留为后续完整后台方案参考。

私有仓库：<https://github.com/De0ta/PiSessionViewer>。源码、测试和文档入库；`pics/`、真实会话、凭据、`.pi/` 与依赖目录排除。

## 模块与调用链

- `src/index.ts`：命令、编辑器安装/清理、重入与任务状态保护、恢复确认。
- `src/editor.ts`：继承 `CustomEditor`，只接管严格空文本且无自动补全的左键，其余交给原生编辑器。
- `src/browser.ts`：自定义 TUI、分组导航、搜索、响应式双栏、预览滚动、取消与异步竞态隔离。
- `src/model.ts`：路径规范化、搜索/分组/排序、终端控制字符清理。
- `src/repository.ts`：公开 SessionManager 发现 API；文件只读、内存解析和分支投影。

入口通过已注册的 `/session-browser` 命令桥接，显式 `expandPromptTemplates: true`。它是扩展命令分派，不向模型提交 prompt。命令只在 TUI 模式运行。

恢复顺序：关闭自定义 UI → 检查空闲和待处理消息 → 用户确认 → 再次检查状态 → `ctx.switchSession(path)` → 返回。重复状态检查防止确认弹窗期间另一个扩展启动工作。切换可能被其他扩展取消；成功后不再复用旧上下文。

## 发现与预览

- 默认 `SessionManager.list(cwd, sessionDir, …, signal)`，按当前 cwd 过滤。
- 全部范围合并默认全局历史与当前 sessionDir，按文件路径去重；Windows 路径忽略大小写和分隔符差异，POSIX 保留大小写。
- 发现 API 的搜索索引包含整份文件中的消息；搜索可能命中非当前分支的内容，而预览只显示当前分支投影。这是明确的索引/预览语义差异。
- 当前会话使用只读上下文的 `buildSessionProjection()`；其他会话只读文件，经 `parseSessionEntries()`、结构/重复ID/循环校验后交给 `SessionManager.inMemory()`。
- 不使用 `SessionManager.open()` 预览，因为它可能迁移并写回旧文件或初始化空文件。
- 预览限制：文件 16 MiB、最近 8 条用户/助手文本、单条 1500 字符。压缩与 context_edit 按 Pi 当前分支投影解析；思考和工具输出不展示。
- 列表扫描不受预览文件上限约束；全局历史多时仍有索引成本。
- 取消旧扫描与预览，同时检查对应 AbortSignal，防止旧异步返回覆盖新选择；退出/关闭时中止任务。

## 编辑器与生命周期

只在没有已有自定义编辑器时安装；冲突时提示使用命令。不注册裸 `left` 快捷键，不全局抢占输入。自动补全、提交和正常光标移动保留给 `CustomEditor`。

`session_shutdown` 关闭浏览器、取消异步操作并仅清理自身编辑器；`session_start` 安装当前运行时入口。跨项目时建议全局或显式加载扩展；仅项目级安装不能保证目标项目继续具有此入口。

## 已执行验证

环境：Windows/Git Bash，Node `v24.13.0`，Pi 依赖 `1.4.0`，TypeScript `5.9.x`。

- `npm run check`：严格类型检查通过。
- `npm test`：21 项全部通过，覆盖入口键码、搜索/分组/路径、只读文件预览、分支与 context_edit、空/损坏/超大文件、宽窄屏宽度、导航、异步过期响应和关闭取消。
- `npm pack --dry-run`：包入口与源码清单核对通过；`npm audit --omit=dev`：未发现漏洞。
- 真实 `discoverAndLoadExtensions()` 从临时项目目录加载扩展；验证命令注册、编辑器保留文字与提交、实际自动补全列表的左键和 Enter、已有编辑器不被覆盖、非 TUI 模式退出、命令重入和 shutdown 后延迟返回。
- 真实 SessionManager 在临时目录发现合成历史；当前会话的内存预览不读取缺失的磁盘文件。
- 宿主替身验证恢复前 UI 已关闭、取消不切换、运行中/待处理消息不切换，以及确认后状态变化时拒绝切换。
- v2 合成会话验证预览前后字节和 mtime 不变；空文件不被初始化。
- 独立只读审查发现确认期间的状态变化竞态；已增加确认后复查及回归覆盖。审查没有发现其他可操作缺陷。

测试使用临时目录、合成会话与宿主替身。

## 操作检查

1. `pi -e .` 加载，在 Windows Terminal 空文本按左键，确认只打开一次；连按、Esc、再次打开。
2. 普通文本、纯空格、多行、中英文、自动补全、确认弹窗与 overlay 中不误抢输入。
3. 真实项目历史的当前范围/全部范围、内容搜索、双栏/窄屏、详情滚动与光标显示。
4. 仅使用可丢弃会话测试恢复、跨项目 cwd、取消切换、目录缺失和 `/reload`；不要对另一个进程正在写入的会话操作。
5. 与用户现有编辑器及其他 UI 扩展共同加载，验证命令退路。
6. 在 Linux/WSL/macOS 分别检查键码、显示与交互。

## 版本范围

v0.1 的功能范围为历史发现、预览与恢复；实时活跃/运行/等待状态、后台保持任务、远程连接、独立会话停止、归档/删除/置顶、worktree、自动命名均在此版本范围之外。mtime 和文件大小仅作为文件信息，其他实例的活动状态需由对应进程确认。
