# v0.3：列表细节、命名与彩色详情

## 本轮范围

按用户十项反馈与底栏配色补充实施。沿用 Pi 1.4 公开 API、全屏覆盖、焦点让出与安全恢复；本轮新增本地标题提炼与独立别名存储。

## 页面

- 搜索条始终显示灰色背景与蓝色 `Search ›`；F3 进入查询，仍区分快捷键浏览与文本输入。
- 项目之间一行留白；每个项目初始最多5条。`Show more` 是独立可选择行，Enter展开5条而不是恢复会话；全部展开后消失，选中第一条新增会话。查询/过滤切换重置展开数，最近活动视图不分页。
- 标题颜色由 ID 决定；状态圈独立着色：默认灰、当前进程进行中蓝、观察到成功结束绿。Status/Updated 始终中性灰，不继承标题身份色。
- `Task details` 下换行展示彩色标题，最多3行，溢出以灰色 `...` 省略。Model/Reasoning 标签灰色，供应商薄荷绿、模型蓝，推理等级使用独立调色板。
- Prompt 和 Last message 用 Pi 原生 Markdown 与主题渲染，支持标题、粗体、列表、代码与表格；不再直接显示原始 Markdown 标记。表格在窄栏仍受终端宽度限制。
- 详情按可用高度分配固定区域；正常窗口同时包含回复和首问，Prompt 至少预留2行。两段溢出使用灰色 `...`，Shift+上下只滚动回复，不把 Prompt 或元数据挤出页面。极小窗口优先保证不溢出，一行高窗口仅展示可容纳的内容。
- 底部快捷键为白色，功能说明为灰色。

## 自动标题与手动修改

- 自动标题采用本地首问首句提炼，剔除常见包装块和代码块、去控制字符、保留前42个Unicode码点，超长追加省略号；**不是额外调用模型的语义摘要**。
- 当前 TUI 会话在成功交互结束、所有边界hook及其context_edit提交后，于 `agent_settled` 使用公开 `setSessionName` 命名；已有名称不覆盖，扩展标记确保只自动处理一次。失败、取消不命名，边界阶段不提前写名称，避免泄漏由更晚的hook删除的文本。浏览器已打开时同步更新当前标题。
- 无原生名称的旧会话，列表先显示本地提炼的回退标题；不会批量改写历史。已命名的旧标题仍保留。
- F2 编辑选中会话标题，Enter 保存、Esc 取消；当前会话使用原生名称。原生 `/name` 也可继续使用。
- 其他会话仅写扩展自有别名，路径为 Pi agent 目录下 `pi-session-viewer/titles/<path+id hash>.json`；不打开历史文件进行写入，不改变其分支/mtime。
- 恢复该历史为当前会话后，在 session_start 中将别名转为原生名称并清理别名；异步读取期间若原生名称已被修改，以新修改为准。
- 别名使用临时文件+原子替换；Windows 临时占用错误有限重试，不先删除目标。并发编辑同一别名采用最后成功写入者，不提供跨进程锁或编辑合并。
- 浏览器内手动命名覆盖旧扫描结果，避免刷新与保存交错时标题回退。

## 状态与隐私边界

当前进程由 `isIdle` / 排队消息和已观察的生命周期计算 Ready、Working、Queued、Completed、Stopped、Error。完成状态仅保存在本次扩展运行内存，重新加载后不能据此恢复历史状态。其他进程历史仍为 Saved，仅表示已保存记录，活动状态需由对应进程确认。

详情遵守当前分支与已提交上下文编辑，不显示思考与工具结果。自动标题在所有边界编辑提交后才生成，不会从已删除首问生成。它不提供对之后产生的编辑、原始历史、Pi 发现索引或已保存名称的追溯隐私擦除。

## 验证与人工检查

自动化使用合成会话、临时目录与宿主替身；`npm run check`、48项 `npm test`、`npm pack --dry-run` 均通过，Windows并发别名测试额外连续运行5次通过。覆盖5/10/全部展开、可选Show more、F2保存/取消/失败、迟到扫描不回退名称、首问删除不泄漏自动标题、命名仅一次、独立别名与原历史不变、Windows并发写入、Markdown/配色/省略、固定Prompt、全屏尺寸及既有恢复安全回归。

两轮独立只读审查提出边界编辑与命名、扫描与命名交错、短窗口滚动跳行问题；已改为提交后命名、保留成功命名覆盖、回复逐行滚动，并补充针对性回归。供应商颜色按用户允许的自选方案保留薄荷绿，不限定为蓝色。

### 操作检查

真实终端可按以下顺序检查交互与显示：

1. `/reload` 后打开浏览器，对照搜索条、项目留白、底栏与详情配色。
2. 在含12条以上可丢弃会话的项目反复展开，确认5→10→全部，Enter不会误恢复。
3. 新建可丢弃会话完成一轮，检查自动标题；F2和原生/name修改，再刷新与恢复检查。
4. 长回复、长首问、Markdown表格/代码、中文与emoji；缩放窗口并滚动回复，检查Prompt与灰色省略。
5. 运行/完成/取消/报错观察当前状态圈；其他历史应保持Saved与灰圈。
6. 对照[v0.2操作检查](fullscreen-v0.2.md#操作检查)检查退出恢复、焦点、自动补全、权限弹窗与跨项目恢复。
