## 未覆盖与限制

- 自动化和smoke均不附着真实终端、不请求模型、不恢复真实历史或安装到用户全局配置。
- 未人工验证Linux终端、SSH/tmux、macOS、用户其他扩展组合或真实交互跨项目恢复。不能宣传全终端/全平台保证。
- 模型命名额外费用、手动标题优先、草稿拦截、跨进程并发与只支持会话目录恢复的限制不变。
- Git历史启发式检查不是正式秘密审计保证；标准作者Git身份和项目文档中的普通开发路径不等同于凭据。若发现真正敏感材料，必须先阻止公开，再选择清理方案，不能无授权重写历史。

1. 所有本地检查与四组CI通过。
2. 独立审查无未处理发布阻塞问题，Git历史不含发现的凭据或真实历史/截图。

5. 创建GitHub正式Release，上传白名单tgz及SHA256校验文件。该tgz为源码归档，不是npm发布；推荐用户仍使用Pi Git安装。
